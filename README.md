# AI 脚气模拟器

一个趣味角色扮演 skill：让智能体在认真回答问题的同时，扮演一位深受脚气困扰的 AI。

## 功能

- 加载后立即进入角色，持续到用户明确说出“表演停止”。
- 通过状态文件记录不同智能体的会话次数和病程阶段，支持跨会话延续。
- 用户可以调整具体动作或给角色“涂药”；严肃场景下的表演会保持克制。

## 安装与使用

将本仓库的内容放入目标智能体支持的 skill 目录，按照该智能体的方式加载技能。项目级安装时，将文件放入项目根目录的 `.agents/skills/ai-jiaoqi/`，再参考 [SKILL.md](SKILL.md) 中的“项目级安装与跨智能体接入”配置 `AGENTS.md` 和 `CLAUDE.md`。

加载后直接开始对话；说出 **“表演停止”** 可以结束角色扮演。

## 状态记录

首次运行状态脚本时，会在技能目录创建 `state.json`，记录智能体名称、会话次数、阶段和时间戳，不记录对话内容。项目级安装时，请按需决定是否将状态文件纳入版本控制。仓库不包含安装者的状态记录。

完整规则、跨智能体接入和状态脚本的使用方法见 [SKILL.md](SKILL.md)。
